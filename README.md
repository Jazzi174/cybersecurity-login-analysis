Cybersecurity Login Activity Analysis

Project Overview

This project analyzes simulated cybersecurity login activity using Python and data analysis techniques.

The goal is to identify suspicious login behavior, potential brute-force attacks, high-activity IP addresses, threat types, and unusual authentication patterns.

Project Objectives

* Analyze login activity and authentication patterns
* Identify potential brute-force attacks
* Identify IP addresses associated with suspicious activity
* Analyze different cybersecurity threat types
* Compare successful and failed login attempts
* Identify repeated login activity from the same IP addresses
* Identify users involved in suspicious activity
* Create visualizations to communicate cybersecurity findings

Dataset

The project uses a simulated cybersecurity login dataset.

Each record represents a login event and contains information such as:

* Source IP address
* Username
* Login status
* Threat type
* Suspicious activity classification
* Other login-related information

The dataset is intended for educational and portfolio purposes.

Analysis Performed

The project includes:

1. Initial dataset inspection
2. Security statistics
3. Brute-force attack analysis
4. Suspicious IP address analysis
5. Suspicious IP visualization
6. Threat type analysis
7. Suspicious login outcome analysis
8. Login activity analysis by IP address
9. Analysis of users involved in suspicious activity
10. Cybersecurity dashboard
11. Key findings and conclusion
